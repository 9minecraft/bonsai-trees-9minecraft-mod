# Bonsai Trees — Automate Wood Farming in Tiny Pots

Bonsai Trees 9minecraft Mod lets you grow tiny trees inside a single pot block. You can plant saplings in different soils and watch them grow into small, complete trees. Grown bonsais look great as decorations on shelves or in gardens. The mod also includes a special menu for each pot where you can set up automatic harvesting.

Miniature Farming: You can grow tiny versions of normal trees inside a single block pot.

## What this build is

An unofficial rebuild of **davenonymous**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
